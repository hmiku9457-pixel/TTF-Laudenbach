# News-Baukasten – Redaktionsübersicht

Der News-Editor bietet fünf frei sortierbare Inhaltsblöcke.

## 1. Text

Der normale Rich-Text-Baustein.

Option:

* **Linksbündig** – Standard für normalen Artikeltext.
* **Zentriert** – für kurze hervorgehobene Textbereiche, Ankündigungen oder Abschlüsse.

## 2. Zwei Spalten

Zwei unabhängige Rich-Text-Felder.

* Desktop: 50/50.
* Mobil: automatisch untereinander.
* Bilder und Tabellen füllen immer nur die jeweilige Spalte.

## 3. Eventankündigung

**Optional.**

Nur verwenden, wenn innerhalb einer News ein konkreter Termin oder eine Veranstaltung hervorgehoben werden soll.

Felder:

* Event – Pflicht
* Datum – Pflicht
* Uhrzeit – optional
* Ort – optional
* Beschreibung – optional

Ein normaler News-Artikel benötigt keine Eventankündigung.

## 4. Trenner

Setzt eine einheitliche horizontale Trennlinie.
Es gibt bewusst keine Designauswahl.

## 5. Abstand

Zusätzlicher vertikaler Abstand zwischen Inhaltsbereichen.

Auswahl:

* Klein
* Mittel
* Groß

Es werden bewusst keine frei eingegebenen Pixelwerte angeboten.

## Bilder und Tabellen

Bilder und Tabellen bleiben Bestandteile des Rich-Text-Editors.

Die Website stellt sie automatisch so dar:

* normale News: volle Artikelbreite,
* Zwei-Spalten-Bereich: volle Breite der jeweiligen Spalte,
* auf kleinen Displays responsive.

Dadurch müssen Redakteure keine Breiten oder CSS-Klassen einstellen.
